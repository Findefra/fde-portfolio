# Platform Onboarding Checklist

Welcome to the Cloud Platform team.

## Day 1
- Request access to the AWS SSO portal
- Join the #platform-ops Slack channel
- Read the incident response overview

## First Week
- Complete the Terraform module contribution guide
- Shadow an on-call shift
- Review the current CIS hardening baseline

## Access Levels
Most documentation is available to all engineers. Production break-glass procedures are restricted to senior SRE and on-call leads.
